## 2. Local development

1. `pnpm install` (pinned via `packageManager`), `supabase start`, `supabase db reset` (applies all migrations + seed).
2. `pnpm dev` runs the web and server workspaces. Local web capture targets the separate `apps/organizer` service exactly as Preview and Production do. Local and Preview intentionally keep the provider planner disabled and fail closed unless a deterministic planner is injected by a test. The Production composition requires its organizer-specific OpenAI key and wires the OpenAI Responses planner, query-embedding retrieval, production cipher, database repository, and AI-only key boundary. `pnpm ios:generate` regenerates the Xcode project from `apps/ios/project.yml`; `pnpm ios:build` performs a code-signing-disabled Simulator build; `pnpm ios:test` runs the native test bundle on the selected iOS 17+ Simulator.
3. `pnpm test` runs package unit tests; `pnpm test:db` runs SQL/RLS tests; `pnpm eval:routing` runs the 175-case deterministic mock safety corpus; and `pnpm eval:routing:pipeline` runs the deterministic production-component retrieval-through-application seam. `pnpm eval:routing:live` is optional, credentialed, and never part of the ordinary local or CI gate.
4. After `pnpm build` and a clean `supabase db reset`, `bash .github/workflows/scripts/milestone-b-http-e2e.sh` starts the built Next.js app and exercises the real HTTP, auth, repository, RPC, and database boundary with synthetic seed data.
5. Native development requires macOS, the repository-pinned XcodeGen 2.46.0 release, and the selected Xcode toolchain. Generation is declarative: edit `project.yml`, configuration files, sources, entitlements, or resources, then regenerate; do not make lasting edits only in the generated project. The script fails closed on a different generator version to prevent non-deterministic project rewrites.

## 8. Performance verification

`pnpm test:retrieval-capacity` is the current automated performance lane: fixture encryption happens before timing, a precomputed 1,536-dimension query excludes embedding-provider time structurally, five cold samples each prove 1,000 authenticated production-opener decrypts, and 20 warm samples each prove a cache hit with zero decrypts while still ranking the exact corpus. It emits JSON sample arrays and p50/p95/max and fails at cold p95 ≥ 2,000 ms or warm p95 ≥ 250 ms. This credential-free lane uses deterministic local key custody and is not cloud KMS/network evidence. Routing evaluation must separately keep candidate recall ≥0.98 and wrong auto-apply ≤0.01 with stale/missing-index cases. The repository does not currently install or run Playwright, k6, Lighthouse, or a browser E2E lane in CI; preview traces, capture load smoke, Lighthouse, and beta telemetry remain future/manual account-bound evidence. Record preview measurements manually for remaining NFRs; never exclude slow successes.

## 10. Backups and restore drill

Supabase scheduled backups (verify plan tier ≥ daily + PITR if available). Quarterly drill: restore to scratch, restore only authorized KMS access separately, verify envelope authentication/content parity without logging plaintext, run deletion replay, time, and record gaps. Restore must retain each intermediate-key record's exact root ARN, wrapped bytes, version, previous root, rewrap count, and four KMS-context identifiers. A backup containing a deleted user's wrapped intermediate key can remain decryptable under the shared root until expiry; deletion copy and restore access controls must reflect this. Pre-cutover plaintext backups remain a documented risk until aged out.
