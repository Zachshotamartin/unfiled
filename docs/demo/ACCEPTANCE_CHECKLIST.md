# Demo acceptance checklist

Status: **pending real recording**

Complete this checklist for both the unedited acceptance recording and the public edit. A checked box must cite a dated record in [RECORDING_LOG.md](./RECORDING_LOG.md), not an assumption.

## Provenance

- [ ] Source commit is recorded and matches the built clients/services.
- [ ] Exact hosted web deployment and commit mapping are proved through the controlled account.
- [ ] Native semantic version, build number, signed configuration, and archive are recorded.
- [ ] iPhone model and iOS version are recorded.
- [ ] The iPhone and browser use the same reviewed backend environment.
- [ ] Provider, semantic-search, BYOK, and private-manual enablement states are recorded accurately.

## Synthetic account and privacy

- [ ] The account and every visible note/capture are synthetic and visibly labeled as such.
- [ ] The fresh acceptance owner began without pre-created flagship destination notes.
- [ ] The hosted seeded owner was provisioned through supported owner-authorized paths, not `supabase/seed.sql` or direct table writes.
- [ ] No real inbox, Apple ID, browser profile, clipboard, contact, notification, or recent-app thumbnail is visible.
- [ ] No OTP, magic link, password, API key, token, cookie, connection string, internal account ID, or private dashboard appears in any frame or audio.
- [ ] Raw takes are stored access-controlled and have a retention owner.

## Native flagship flow

- [ ] The Lock Screen widget exposes no note, capture, destination, receipt, or token content.
- [ ] Widget activation opens a blank focused composer with the keyboard ready.
- [ ] Shopping capture receives durable acknowledgement and produces the correct three unchecked items or an honest Review state.
- [ ] One checklist item is changed using the normal interactive surface.
- [ ] Workout capture preserves the raw source and produces editable structured fields without inventing units.
- [ ] A numeric workout field is changed and the current revision is shown.
- [ ] The principle capture preserves the exact source and visibly distinguishes any generated interpretation.
- [ ] No historical attribution is asserted without evidence.
- [ ] `add bananas` reaches the current shopping note or an honest Review state.
- [ ] Receipts expose the correct destination and applicable Undo/correction controls.

## Web and search

- [ ] The same synthetic owner opens the same current notes on the hosted web client.
- [ ] At least one iPhone change is visibly current on web.
- [ ] All-notes lexical search is clearly distinguished from AI-assisted-only search.
- [ ] AI-assisted search is shown only if its deployed provider, ticket, KMS/database, canary, and degradation gates are recorded green.
- [ ] Private-manual content is never entered into or exposed through the AI-assisted demonstration.
- [ ] A stale/incomplete/failing semantic path is never edited into an apparent semantic success.

## Correction, Undo, and failure truthfulness

- [ ] One real correction or Undo is performed through the supported product action.
- [ ] Its receipt and current revision match on both clients.
- [ ] No database patch, fixture branch, hidden admin action, or recreated result is represented as user behavior.
- [ ] The public edit preserves chronological order.
- [ ] Every removed wait or speed ramp is harmless and visibly labeled when it changes perceived latency.
- [ ] Errors, Review outcomes, and disabled features are described accurately rather than hidden.

## Accessibility and publishing

- [ ] Final UI text remains legible at the published resolution.
- [ ] Disclosure, receipt state, and action labels are never cropped.
- [ ] Captions have been re-timed against the final locked audio.
- [ ] Transcript matches the final narration.
- [ ] Captions, transcript, poster, public URL, and SHA-256 are recorded in the demo manifest.
- [ ] The description identifies the account/content as synthetic.
- [ ] The closing status language agrees with `docs/STATUS.md`.
- [ ] Music, fonts, screenshots, and other third-party assets have documented usage rights.
