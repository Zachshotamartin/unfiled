# Soft Index

Soft Index is a planned mobile-first notes app that lets a person capture a thought before deciding where it belongs. The system keeps the original capture, proposes or applies a reversible organization action, and makes every result easy to inspect and correct.

Current status: product and implementation planning only. No application code has been bootstrapped yet.

Start with the [full build plan](./docs/BUILD_PLAN.md).
