# Unfiled Visual Generation Prompt Set

Mode used: **built-in image generation**, using `unfiled-brand-board-v1.png` as the reference image after the identity board was established.

This is the normalized prompt set for regenerating the visual direction. Preserve the design bible below for every image; add exactly one screen or website-section brief at a time.

## Shared design bible

Create a premium design reference for `unfiled`, a mobile-first self-organizing notes product. The central idea is that loose thoughts settle into useful order. Use a lowercase wordmark and an open geometric `u` / intake-tray symbol with one persimmon rectangular paper slip entering. Palette: Ink `#0B0C0E`, Graphite `#181B1F`, Warm Paper `#F2EFE8`, Persimmon `#EE6F55`, Fog `#9DA3A6`. Use wide editorial neo-grotesk typography, compact mono metadata, restrained hairlines, strong negative space, subtle tactile paper grain, and crisp native-feeling UI. AI stays backstage; organization is visible and reversible.

Never use gradients, purple or blue AI glow, glassmorphism, generic SaaS cards, fake charts, stock-photo people, sparkles, brains, heads, neural nodes, folder illustrations, rainbow sticky notes, chat-bubble primary UI, excessive pills, or card-inside-card layouts. Make visible copy readable and correctly spelled.

## Identity board

Create one high-end 3×3 brand-guidelines board covering: primary symbol and wordmark, geometric construction, Lock Screen application, tagline, authoritative palette, typography, capture receipt, tactile embossed application, and fragments-to-categories concept. Keep the board sparse and editorial rather than a dense corporate brand sheet. Exact brand line: `Just write. It finds its place.`

## Mobile screens

Generate each as a fresh standalone iPhone screen inside a subtle premium phone frame:

1. **Lock Screen:** system-authentic dark Lock Screen with a compact Unfiled accessory widget and exact text `Write something`; no note content exposed.
2. **Quick capture:** focused composer with keyboard open, exact capture `add bananas to the shopping list`, one coral submit control, no organization choices.
3. **Today:** large `Today` title and receipt ledger with `Added to Shopping`, `Updated Push Workout`, and `Added to Mindset`.
4. **Notes:** searchable manual library with `All` and `Spaces`, and rows `Shopping`, `Workouts`, `Mindset`, `Projects`.
5. **Shopping note:** checklist including milk, spinach, batteries, and bananas, with provenance `Updated from 2 captures`.
6. **Review:** original Roosevelt-method capture, proposed `Mindset / Principles` destination, and `Accept`, `Move`, `Keep in Inbox`, `Original preserved`, `Undo available` controls.

## Marketing website sections

Generate exactly six separate horizontal 16:9 images, one section per image:

1. **Hero:** giant centered `Just write. It finds its place.`; supporting `Notes that organize themselves.`; refined navigation; `Join the waitlist`; phone fragment and slips converging into the mark.
2. **Problem:** Warm Paper material switch with asymmetric layout; `No titles. No folders. No filing first.`; fragments `milk`, `push workout: 4×8`, and `Roosevelt method` aligning into an index.

4. **Use cases:** `Whatever is on your mind.`; gapless fields `SHOPPING`, `WORKOUTS`, `MINDSET`, `PROJECTS`; a single coral slip connects them.

6. **Final CTA:** `Write it down before it disappears.`; `Join the waitlist`; `Web + iPhone`; one slip hovering above an oversized intake tray and a minimal footer.

## Authenticated desktop web app

Create one standalone 16:10 signed-in product screen with no browser chrome. Use a narrow left rail for `Today`, `Notes`, `Spaces`, `Review`, and `Search`; a dominant Today workspace with the `Write something` composer and continuous receipt ledger; and an optional right context pane showing original capture, destination `Mindset / Principles`, `Open note`, `Undo`, and `Original preserved`. It must feel like an editor and ledger, never an analytics dashboard.
